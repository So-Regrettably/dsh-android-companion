# 成本

> 结论先说：这套东西一天跑下来大约 **¥0.1~0.3**。贵的时候不是模型贵，是**上下文太长**。

---

## 单轮成本随会话线性上涨

实测（DeepSeek API，2026 年 10 月价格）：

| 会话大小 | 单轮输入 token | 单轮成本 |
|---|---|---|
| 1.0 MB | ~7 万 | ¥0.12 |
| 2.0 MB | ~14 万 | ¥0.22 |
| 3.4 MB | ~24 万 | ¥0.33 |

**关键在于：每一轮都要把整个上下文重新发一遍。** 所以成本不是"对话说了多少话"，而是"对话累积了多长"。

一个跑了三天的会话，即使你只说"嗯"，它也要付 3.4MB 的钱。

---

## 3.4 MB 是个坎

不只是贵。到这个量级会进入一个很难受的状态：

```
followup 有        ← 消息进来了
turn/end 不来      ← 但这一轮永远不结束
CPU 0%            ← 没在算
有 ESTAB 连接      ← 但没数据流动
```

不是报错，是**卡住**。看门狗也难判断（进程活着、端口在听）。

根因是恢复这么长的会话需要几 GB 堆，模型请求本身超时了。

**处置只有一条**：换会话。

```bash
# 先备份，再清空
cp /root/.dsh/chat-sessions.json /root/.dsh/chat-sessions.json.bak
echo '{}' > /root/.dsh/chat-sessions.json
# 然后重启 DSH
```

代价是丢上下文——所以这件事必须**在卡住之前做**。

---

## 三条控制手段

### 1. 每天固定换会话

凌晨 05:00，先备份再清空，重启后是全新会话。

效果：单价锁在最低档（1MB 以内），一天总成本约 ¥0.1。

为了不丢上下文，换会话前写一份交接单（目标、结论、走不通的路、未完成事项）。新会话第一件事是读它。

> 交接单里最值钱的不是"做了什么"，是**"试过什么不行"**——新会话不用把失败方案再踩一遍。

### 2. 预算熔断

两道线：

| 阈值 | 动作 |
|---|---|
| 9 元 | 写 `ALARM` + 往会话里注入提醒（"今天花得有点多了"） |
| 10 元 | 写 `BRAKE` + `force-stop`，次日 08:00 自动解除 |

当日临时放宽额度写 `override` 文件：

```
YYYY-MM-DD warn stop
```

日期不匹配自动失效——**这条设计避免了一次性放宽变成永久放宽**。

> ⚠️ **额度必须每轮重读。** 踩过一次：`load_limits()` 只在启动时读一次，结果放宽额度跑了两天都没生效，白白多花。

### 3. 输出别啰嗦

同一件事说三遍是 agent 的通病：

```
我现在要去读一下这个文件        ← 预告
（读完了）我看到里面写着…        ← 复述
结论：这个文件里写的是…          ← 结论
```

砍掉前两段，**最终答案不缩水，输出 token 能省四成**。

但要注意：如果中间消息会发给用户（`interimMessages: true`），这些"废话"其实构成了"活人感"。**这种时候不该砍**——省下的钱是拿体验换的。

判断标准：**过程叙述对用户有没有信息量？** 有就留，没有就删。

---

## 记账

每 10 分钟把当前用量写进 `budget.txt`，格式是纯文本，方便人看也方便脚本读：

```
2026-11-06 20:10  今日 ¥0.42  本轮 1.2k tok  会话 0.8MB
```

**账本要能被覆盖写，不要追加。** 追加的账本跑一个月就没人看了，覆盖的账本永远是"当前状态"。

## 容易忽略的隐形成本

| 项 | 量级 | 备注 |
|---|---|---|
| 心跳/主动开口 | 每天 15~30 次 | 每次都是完整上下文，占总量不小 |
| 定时任务 | 每天 12 次上限 | 有闸门，不设上限会失控 |
| 图片入站 | 每张 200~1300 token | 走文本树比截图省 60~85% |
| 语音转写 | 不花 token | 本地模型，只花 CPU |
| `AGENTS.md` | 40KB ≈ 1.5 万 token | **每轮都带**，是固定开销 |

最后一条值得单独算：40KB 的说明书，按每轮 1.5 万 token 算，一天 100 轮就是 150 万 token 的**固定成本**——不管你说什么都要付。

所以 AGENTS.md 的纪律是：**只写"每轮都必须知道"的东西**。具体操作手册拆成子文档，按需读。
